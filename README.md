# Atom Asistan - Home Assistant add-on

AtomS3R tabanli sesli ev asistaninin kopru add-on'u: OpenAI Realtime
API ile konusur, Home Assistant'taki cihazlari kontrol eder, cihazin
128x128 ekranindaki yuzu yonetir.

## Kurulum

Ayarlar -> Eklentiler -> Eklenti Magazasi -> sag ust uc nokta ->
**Depolar**, sonra:

```
https://github.com/Arda-Apps/atom-asistan-addon
```

Add-on magazada **Atom Asistan Bridge** olarak gorunur. Kurduktan sonra
add-on sayfasindaki **Auto update** anahtarini acarsan yeni surumler
kendiliginden gelir.

Ayarlarin tamami `atom_asistan/DOCS.md` icinde anlatiliyor.

## Bu depo uretiliyor

Buradaki dosyalar elle duzenlenmiyor; ana depodan
`tools/addon_yayinla.py` ile uretiliyor. Buraya yapilan degisiklik bir
sonraki yayinda silinir.
